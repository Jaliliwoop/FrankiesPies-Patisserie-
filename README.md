# Franky's Pies and Patisserie Supply

Static website for https://frankypie.cafe.

Publish the repository root with GitHub Pages. All website photographs are stored in `assets/` and loaded using relative local paths. Keep that folder with `index.html`, `style.css`, `script.js` and `catalogue.json`. No external image service or build step is required.

The catalogue contains 97 listings, including a single pie listing with eight fillings. Enquiries prepare an email draft for the visitor to review and send.
